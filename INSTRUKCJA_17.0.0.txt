AIO Panel 17.0.0 — instalacja i podmiana GitHub

REPOZYTORIUM
https://github.com/OliOli2013/PanelAIO-Plugin

GITKRAKEN / LINUX MINT
1. Otwórz lokalne repozytorium PanelAIO-Plugin i upewnij się, że nie masz własnych niezapisanych zmian.
2. Rozpakuj AIO-Panel-17.0.0-GITHUB.zip.
3. Skopiuj jego zawartość bezpośrednio do katalogu repozytorium, zastępując pliki. Nie usuwaj katalogu .git. ZIP ma pliki w katalogu głównym, bez dodatkowego folderu nadrzędnego.
4. W jednym commicie zapisz źródła, control/, release/ z pakietami 17.0.0, version.txt, update.json, SHA256SUMS.txt i installer.sh. Zatwierdź i wykonaj Push na main.
5. Nie publikuj najpierw samego version.txt. Aktualizator wymaga spójnej wersji plików i sumy pakietu. GitHub Release jest opcjonalny, bo pakiety znajdują się również w release/ repozytorium.

IPK — OBRAZY OPKG
Prześlij przez FTP dokładny plik enigma2-plugin-extensions-panelaio_17.0.0_all.ipk do /tmp.
W SSH/Telnet/PuTTY wykonaj:
opkg --force-reinstall install /tmp/enigma2-plugin-extensions-panelaio_17.0.0_all.ipk
Po udanej instalacji wykonaj restart GUI z menu tunera.

DEB — OBRAZY DPKG
Prześlij enigma2-plugin-extensions-panelaio_17.0.0_all.deb do /tmp.
W terminalu wykonaj:
dpkg -i /tmp/enigma2-plugin-extensions-panelaio_17.0.0_all.deb
Po udanej instalacji wykonaj restart GUI z menu tunera.
DEB nie potwierdza zgodności wszystkich historycznych dodatków z DreamOS. Szczegóły w audycie.

AKTUALIZACJA ONLINE PO PUSH
Aktualizacja z 16.0.3 korzysta z dotychczasowego adresu installer.sh.
Instalacja panelu przez terminal, z pobraniem do pliku:
wget -O /tmp/aio-panel-installer.sh https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh && /bin/sh /tmp/aio-panel-installer.sh
Nie opublikowano tych zmian na GitHubie za Ciebie. Dopóki nie wykonasz Push, adres prowadzi do poprzedniej wersji.

DODATKI
Pozycje [feed obrazu] korzystają z repozytoriów zainstalowanego systemu. Nie każdy feed ma wszystkie dodatki. Brak pakietu powoduje czytelny błąd. Instalacja skinu nie przełącza go automatycznie.

WERYFIKACJA NA TUNERZE
Kompilacja Python 2.7.18 / Python 3 i testy automatyczne przeszły. Nie wykonano testów na fizycznym tunerze. Przeczytaj AUDYT_17.0.0.md przed traktowaniem wydania jako sprawdzonego na konkretnym modelu.

POPRAWIONA PACZKA 17.0.0 — 4 PAŹDZIERNIKA 2026
Numer wersji celowo nie uległ zmianie. Jeżeli masz już 17.0.0, użyj powyższego --force-reinstall: zwykłe opkg install może zachować wcześniejszą paczkę. Po podmianie restart GUI jest konieczny, aby usunąć stary kod z pamięci.
Zakładka AIO / Aktualizacje znajduje się na końcu.
Skórki z feedu: panel odczytuje pakiety z lokalnych indeksów własnego obrazu; pokazuje tylko dostępne lub zainstalowane. Nie dodaje obcych feedów. Jeśli katalog skórek jest pusty, odśwież feedy (opkg update) i otwórz panel ponownie. Historyczne instalatory skórek spoza feedu pozostają osobnymi pozycjami.
Listy: przy każdym otwarciu panelu weryfikacja pobiera archiwa w tle. Puste odpowiedzi, HTML, uszkodzone ZIP/TAR, niebezpieczne ścieżki i brak danych Enigma2 powodują ukrycie pozycji. Błędna lista wróci po kolejnym otwarciu, jeżeli jej źródło znów udostępni poprawną paczkę. Daty metadanych nie omijają kontroli.
Kontrola nie instaluje kanałów ani nie rozpakowuje plików do /etc/enigma2. Deduplikacja pobrań jest tylko w obrębie jednego otwarcia, bez pamiętania sukcesu między otwarciami. Limit: 4 połączenia, 12 s na operację sieciową, 60 s na serię, 16 MiB pobrania, 64 MiB po rozpakowaniu, 12000 wpisów. Timeout ukrywa niesprawdzoną listę; otwórz panel ponownie po przywróceniu sieci. Ponowna kontrola podczas instalacji pozostaje aktywna.
